# document-specs

Docs repo and source of truth: specs (Spec Kit), ADRs, the order schema and OpenAPI contracts.

## Read first
- [agent-workflow.md](https://github.com/super-good-sg/document-specs/blob/main/docs/agent-workflow.md) and the [CLAUDE.md standard](https://github.com/super-good-sg/document-specs/blob/main/docs/claude-md-standard.md).
- The spec, contract or ADR linked from your Linear ticket (project SuperGood). Linear is the source of truth for work.

## Commands
- No build. Docs only.
- Spec Kit: use the `speckit-*` skills in `.claude/skills/` (specify, plan, tasks, ...).
- Lint: TODO (markdown lint, if added).

## Folder map
- `docs/`: agent workflow, this standard, the business doc, ADRs (`docs/adr/`), architecture diagrams (`docs/architecture/`), the reverify register (`docs/reverify.md`), the design file and screen list (`docs/design/`), and later contracts (`docs/contracts/`).
- `.specify/`: Spec Kit config, templates and constitution (`memory/constitution.md`).
- `.claude/`: Spec Kit agent skills.

## Where things live
Specs, ADRs and contracts (OpenAPI, order schema) all live in [document-specs](https://github.com/super-good-sg/document-specs). See the [standard](https://github.com/super-good-sg/document-specs/blob/main/docs/claude-md-standard.md#where-things-live-all-in-document-specs) for paths.

## Conventions
- Branch `type/SIE-xxx/short-summary`, commits and PR title `type(SIE-xxx): message` (see [CONVENTIONS.md](https://github.com/super-good-sg/document-specs/blob/main/docs/CONVENTIONS.md)). One ticket, one branch, one PR. Never merge your own PR.
- Reuse approved patterns; stop and ask before adding a new library or convention.
- No secrets in code or commits.
- New or changed behavior starts as a spec here, merged by PR before dependent code.
- Contract changes land here first; code repos regenerate from them.

## Do not touch
- `docs/architecture/*.html` (generated by archify from the JSON next to it; edit the JSON and regenerate).
- `.specify/` and `.claude/skills/` (generated by Spec Kit; update via the tool). `.claude/settings.json` is edited by PR like any file.
